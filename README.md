# WinterTech — Landing Page Oficial

Landing page moderna, responsiva y de alto impacto para **WinterTech**, empresa de desarrollo de software, aplicaciones web, aplicaciones móviles y consultoría tecnológica.

## 🚀 Tecnologías Utilizadas

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconografía**: [Devicon](https://devicon.dev/) y [Lucide React](https://lucide.dev/)
- **Diseño**: Interfaz moderna con navbar estilo Apple iOS frosted glass, micro-interacciones fluidas y carrusel infinito de tecnologías.

## 📦 Estructura del Proyecto

- `src/components/Navbar.jsx`: Barra de navegación fija con efecto frosted glass y cápsula morphing elástica.
- `src/components/Hero.jsx`: Sección principal con llamada a la acción y personaje interactivo.
- `src/components/AboutUs.jsx`: Perfiles de co-fundadores (Fabian Ramirez y Jesus Rocha) junto con la Misión y Visión.
- `src/components/Services.jsx`: Catálogo de 4 servicios clave (Web, Móvil, Landing Pages y Consultoría).
- `src/components/Projects.jsx`: Proyectos destacados (AxisLab, PokeNex, Coyllor).
- `src/components/TechCarousel.jsx`: Carrusel continuo con el stack tecnológico de la empresa.
- `src/components/Contact.jsx`: Formulario y canales de contacto directo.
- `src/components/Footer.jsx`: Pie de página y enlaces corporativos.

## 🛠️ Instalación y Uso

1. **Instalar dependencias:**
   ```bash
   npm install
   ```

2. **Iniciar servidor de desarrollo:**
   ```bash
   npm run dev
   ```

3. **Generar compilación para producción:**
   ```bash
   npm run build
   ```
